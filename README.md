# machine-learning-zoomcamp_capstone_project
Final project for Machine Learning Zoomcamp 2025






Paso 1: Consigue la Key (kaggle.json)

* Entra en kaggle.com e inicia sesión (puedes usar tu cuenta de Google).
* Haz clic en tu foto de perfil (arriba a la derecha) -> Settings.
* Baja hasta encontrar la sección "API".
Haz clic en el botón "Create New Token".
* Se descargará automáticamente un archivo llamado kaggle.json a tu ordenador.
* Mueve ese archivo a la carpeta raíz del proyecto.
